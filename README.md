# Blendgine × WebMCP

**Scientific pairing intelligence meets human sensory intelligence.**

Blendgine is a WebMCP reference experience exploring a limitation of AI-assisted flavor formulation: an agent can reason over chemistry and structured ingredient evidence, but it cannot taste.

This challenge build creates a structured collaboration loop:

**evidence predicts → agent proposes → human tastes → agent asks → human teaches → Blendgine records → pairing knowledge improves**

The interaction is intentionally playful. Scientific detail stays available when the human wants it, while structured evidence and provenance remain rigorous underneath the conversation.

## Challenge scope

This repository is a fresh implementation for the 2026 WebMCP Challenge. It will demonstrate WebMCP tools for:

- inspecting evidence-backed ingredient and pairing information;
- generating a pairing hypothesis without pretending the agent can taste;
- presenting a small formulation for human evaluation;
- capturing structured human sensory observations;
- preserving provenance between scientific evidence, model hypotheses, and human observations;
- inspecting what the human actually taught the system;
- refining the next pairing/formulation from both evidence sources.

## Core principle

> AI can know the chemistry of flavor. It cannot know what something tastes like. Blendgine gives the two intelligences a way to meet.

A tasting observation is evidence about a specific formulation, preparation, concentration, and context. It is not automatically promoted into a universal claim about taste.

## Provenance

Blendgine and related formulation concepts predate this challenge. The WebMCP interface, reference implementation, challenge demo, evaluation suite, and challenge-specific sensory evidence loop in this repository are new challenge work. Commit history in this repository is preserved as dated implementation evidence.
